# Presentation guide — 5 minutes

Use the five scripts below in order. The timings match the presentation outline: introduction (0:30), SQL demonstration (2:00), findings and recommendations (1:00), challenge or limitation (1:00), and close (0:30). Together they run for five minutes.

| Section | Duration | Prepared script |
|---|---:|---|
| 1. Introduction | 0:30 | [01-introduction.md](01-introduction.md) |
| 2. SQL demonstration | 2:00 | [02-sql-demonstration.md](02-sql-demonstration.md) |
| 3. Key findings and recommendations | 1:00 | [03-key-findings-and-recommendations.md](03-key-findings-and-recommendations.md) |
| 4. Technical challenge or limitation | 1:00 | [04-technical-challenge-or-limitation.md](04-technical-challenge-or-limitation.md) |
| 5. Close | 0:30 | [05-close.md](05-close.md) |

Rehearse once before recording. Keep result sets legible, narrate the business purpose instead of reading SQL aloud, and leave the query result visible while explaining it. The SQL demonstration uses the project's PostgreSQL reference schema and dataset; see the main [README](../README.md) for setup commands.
